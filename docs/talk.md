# План рассказа (10–15 минут, для людей вне домена)

1. Задача: агенту нужна внешняя модель, но персональные данные отдавать нельзя → барьер «маска туда — значения обратно, в нужном падеже».
2. Почему трудно: десять разных классов, морфология русских ФИО, контекст (дата рождения vs дата договора), чаты без заглавных.
3. Как мерить: почему не F2 (таблица «замаскировать всё» = 0.73 по F2 и 0.15 по нашей метрике), гармоническое среднее по классам.
4. Как работает арена: train / public / private, лимит решений, журнал.
5. Как шла эволюция: кривая, 2–3 ключевых поворота (ЧП2–ЧП3).
6. Что получилось на private и почему это работает.
7. Что интересного нашлось по пути: класс, пропавший из private при разбиении по семействам; склонение как половина задачи.
