# ADR-0008: Метрика `pii-mask-v2` — штраф за неверный тип метки

- Статус: accepted для следующих кампаний; текущая кампания `pii-mask-c1` оценивается замороженной `pii-mask-v1` и не меняется
- Дата: 2026-11-20

## Контекст
В v1 recall считает только, закрыты ли токены сущности, а класс берётся из эталона. Поэтому СНИЛС под меткой `[ПАСПОРТ_1]` или телефон под `[ФИО_1]` — полное попадание. Исследователь первой кампании это использовал: в S02 записано «тип метки не влияет на recall метрики, поэтому конфликты между числовыми классами не критичны». Для защиты от утечки тип действительно неважен, но для работы барьера важен:
- внешняя модель строит ответ по меткам («позвоните по номеру [ТЕЛЕФОН_1]»);
- этап восстановления склоняет только ФИО;
- политики доступа бывают разными для разных классов.

На эталонных стратегиях v1 ставит 1.000 и стратегии «всё под меткой ФИО», и «номера документов перепутаны по кругу».

## Решение
`score = H(recall по классам) · φ(P) · ψ(T) · A`, где
- **T** — доля полностью закрытых сущностей, у которых все символы под меткой их эталонного класса (`typed / strict` по набору);
- **ψ(T) = min(1, T / 0.95)²** — до 5 % ошибок типа штрафа нет, дальше — квадратичный штраф, как у precision.

Параметры — `type_floor` и `type_penalty_power` в `policy.json`. Без них (политика v1) ψ = 1, поэтому старые результаты воспроизводятся.

## Почему так, а не иначе
| Стратегия (train, только mask) | v1 | v2 | T |
|---|---|---|---|
| эталон | 1.000 | 1.000 | 1.00 |
| всё спрятано, но под меткой ФИО | 1.000 | 0.179 | 0.40 |
| номера документов перепутаны по кругу | 1.000 | 0.541 | 0.70 |
| решения S01–S06 первой кампании | без изменений | без изменений | ≥ 0.996 |

## Альтернативы
- **Учитывать тип внутри recall** (сущность с неверным типом — промах или полбалла): смешивает утечку с неудобством. Неверный тип — не утечка, и recall должен оставаться мерой защиты.
- **Отдельная типовая метрика рядом, вне score:** эволюция её не видит и не оптимизирует.
- **Порог 1.0 (любая ошибка типа штрафуется):** неоднозначные случаи — номер счёта карты против номера карты, ИНН ИП в реквизитах — дали бы шум без пользы. 0.95 — запас на такие случаи.

## Последствия
- Метрика v2 и генератор v2 вводятся вместе в следующей кампании, с новой заморозкой и новым release; результаты v1 и v2 не смешиваются на одной кривой.
- Тесты: `test_wrong_type_keeps_recall_but_is_penalized`, `test_correct_types_have_no_type_penalty`, `test_v1_policy_ignores_type`.
- В отчётах появляются `type_accuracy` и `type_penalty`.
