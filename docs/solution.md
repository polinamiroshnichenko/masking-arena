# Текущее лучшее решение (ЧП2): S02 `rules-a1`, арена mask

Итоговое решение появится после финализации; здесь — лучший кандидат на 2026-11-20.

- **Идея.** Baseline терял recall на структурных классах не из-за неоднозначности, а из-за узких форматов. S02 расширяет форматы, но ставит метку только при подтверждении: по контексту (для дат) или по контрольной сумме и ключевому слову (для 11–12-значных чисел). Так recall растёт, а precision не падает.
- **Алгоритм** (`solve.py`, только stdlib, детерминированный):
  1. Набор регулярных выражений по классам: EMAIL, АДРЕС, ДАТА_РОЖДЕНИЯ, ПАСПОРТ, СНИЛС, ИНН, СЧЕТ, КАРТА, ТЕЛЕФОН, ФИО (правила ФИО — из baseline).
  2. Адрес: ядро «тип улицы + название + дом [+ корпус/квартира]», «д.» необязателен, «дом-квартира» через дефис, чатовая форма. Слева по запятым присоединяются индекс, регион и город.
  3. Дата рождения: дд.мм.гггг, дд/мм/гггг, гггг-мм-дд, «д месяц гггг», «дд» месяц гггг. Только с контекстом: «рождения/родился/др» слева в строке, «г.р.» справа или дата сразу после ФИО.
  4. СНИЛС и ИНН: слитные числа — только с контрольной суммой или ключевым словом. Паспорт: «серия … номер/№ …», слитные 10 цифр после «паспорт».
  5. Пересечения разрешаются по приоритету класса (EMAIL > АДРЕС > дата > документы > карта > телефон > ФИО), затем по длине. Одинаковые значения получают одну метку.
- **Почему работает:** у синтетики конечный набор форматов, и для чисел есть надёжные признаки (контрольные суммы, ключевые слова), а для дат — однозначный контекст.
- **Где ломается:**
  - ФИО: recall 0.689 на train, правила не менялись. Не ловятся «Имя Фамилия», «Фамилия Имя Отчество» в косвенных падежах, нижний регистр в чатах.
  - Приветствие уходит под метку ФИО («Уважаемый [ФИО_1]»), это наследие regex baseline.
  - На реальных документах адреса находятся в 12% случаев (слитные и в верхнем регистре).
- **Сложность:** O(длина текста × число шаблонов), около 0.3–0.5 с на пример с запуском контейнера; токенов модели — 0.
- **Результат:** train 0.956, public 0.969 против baseline 0.645 / 0.535; на реальных документах 0.538 против 0.000.
- **Как арена к нему пришла:** первое же предложение ветки A (структурные классы) по гипотезе из анализа ошибок baseline; подробно — [evolution.md](evolution.md), эпизод 1.
