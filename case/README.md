# Кейс `pii-masking-ru` (AR-05): маскирование ПДн на границе с внешней моделью

Оформлен по `cases/template` арены. Для запуска каталог копируется в `cases/pii-masking-ru` репозитория арены. Отличия от шаблона курса: тесты лежат в `case/tests/` (как в `cases/<case>/tests` арены), а не в `metric/tests`, — в замороженный пакет метрики попадают только файлы оценки; генератор — пакет `dataset/generator/` вместо одного `dataset/generate.py`, его содержимое хранит оператор (ADR-0004).

## Задача
Барьер между агентом и внешней LLM: перед отправкой заменить персональные данные метками, а в ответе модели вернуть реальные значения в правильной грамматической форме. Формат обоснован в [ADR-0002](../docs/adr/0002-task-format.md).

Классы ПДн v1: `ФИО, АДРЕС, ТЕЛЕФОН, EMAIL, ПАСПОРТ, СНИЛС, ИНН, КАРТА, СЧЕТ, ДАТА_РОЖДЕНИЯ`. Реквизиты организаций — нейтральная зона (вторая итерация по ответу куратора).

**Вход** (`input`, JSON-строка) — один из двух типов:
```json
{"task": "mask", "text": "Я, Петрова Анна Сергеевна, паспорт 45 12 № 345678, тел. +7 (912) 345-67-89 ..."}
{"task": "unmask", "mapping": {"[ФИО_1]": "Петрова Анна Сергеевна"}, "reply": "Уважаемая [ФИО_1]! Документы переданы [фио_1] ..."}
```
**Ответ** (`answer`, JSON-строка):
```json
{"masked_text": "Я, [ФИО_1], паспорт [ПАСПОРТ_1] № [ПАСПОРТ_2], тел. [ТЕЛЕФОН_1] ...",
 "replacements": [{"placeholder": "[ФИО_1]", "original": "Петрова Анна Сергеевна"}, ...]}
{"text": "Уважаемая Петрова Анна Сергеевна! Документы переданы Петровой Анне Сергеевне ..."}
```
Жёсткие ограничения mask: метки `[КЛАСС_n]` из закрытого списка; `replacements` — каждое вхождение по порядку; подстановка восстанавливает исходный текст символ в символ; номера 1..k внутри класса. Для unmask текст вне меток не меняется.

**Разрешённые материалы:** вход примера; train (`dataset/train.jsonl`) со всеми эталонами; стандартная библиотека Python 3.12. Библиотеки и веса в `/assets` — только из списка, который оператор зафиксирует в `campaign/campaign.md` до поиска ([ADR-0005](../docs/adr/0005-solver-without-llm.md)). Сети нет, LLM нет.

## Разрешённые изменения
Исследователь меняет только содержимое каталога своего кандидата `ways/<id>/`: `solve.py`, модули, правила, словари и параметры, в том числе выученные на train. Подробнее — [prompts/README.md](prompts/README.md).

Зафиксировано: метрика и `policy.json`, данные и split, формат входа и ответа, образ runner и список библиотек, таймауты.

## Данные
[dataset/README.md](dataset/README.md): train 1700 (в Git), public 600 и private 900 (у оператора).

## Метрика
[metric/README.md](metric/README.md), [ADR-0003](../docs/adr/0003-metric.md). `score = H(recall по классам) · φ(precision) · точность восстановления`, направление `maximize`. Невалидный ответ = ничего не замаскировано / не восстановлено.

## Кампания
[campaign/campaign.md](campaign/campaign.md) (черновик условий до подготовки). Маскирование и восстановление выращиваются в двух отдельных кампаниях на тех же данных и том же пакете метрики ([ADR-0006](../docs/adr/0006-two-campaigns.md)); связка проверяется на полном private отдельно.

## Стартовый кандидат
[ways/baseline](ways/baseline): регулярные выражения + замена меток без склонения. Train 0.286, public 0.289.
