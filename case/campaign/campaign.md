# Условия кампаний

Условия заморожены 2026-11-20 при подготовке по `prompts/prepare.md` арены. Две отдельные кампании, этапы по очереди ([ADR-0006](../../docs/adr/0006-two-campaigns.md), [ADR-0007](../../docs/adr/0007-researcher-and-deployment.md)).

| | mask | unmask |
|---|---|---|
| Release / журнал | `pii-mask-c1` / `operator/arena/mask/search/search.sqlite3` | `pii-unmask-c1` / `operator/arena/unmask/search/search.sqlite3` |
| Примеры | только `task = mask` | только `task = unmask` |
| train / public / private | 1200 / 420 / 630 | 500 / 180 / 270 |
| Метрика | `pii-mask-v1` (заморожена, sha256 lock `a9e1b696…`); итог на наборе = H · φ(P) | `pii-mask-v1`; итог на наборе = A |
| Решатель | образ `pii-mask-runner:1` (natasha 1.6.0, razdel 0.5.0), без сети и LLM, 60 с на пример | образ `pii-unmask-runner:1` (pymorphy3 2.0.4, razdel 0.5.0) |
| Лимит предложенных решений | **12** | **6** |
| Финалистов K / итоговых N | 3 / 1 | 2 / 1 |
| Модель исследователей | Claude Sonnet 5.5, effort High, Claude Code 2.1.318 (одна на обе кампании) | то же |
| Private | токен и отправка — только у оператора (`arena_ops.py submit-private`) | то же |

Полные условия, подставленные в рабочую копию исследователя: `deploy/local/campaign/<c>/campaign.md`, конфигурация — `deploy/local/campaigns.json`, свидетельства готовности — [docs/preparation.md](../../docs/preparation.md).

**Почему такой лимит.** Оценка кандидата дешёвая (около 3 минут, 0 токенов решателя), узкое место — лимит подписки Pro у исследователя. 12 + 6 — объём, который реально довести до финализации к защите; лимит зафиксирован до старта и не меняется.

**Финализация.** После исчерпания лимита (или команды человека «стоп») исследователь после ревью фиксирует ровно K финалистов `evaluator.search finalize --bundle`; оператор проверяет готовность и отправляет пакет на private один раз. Правило выбора финалистов: качество на public и train, разнообразие механизмов, устойчивость, отсутствие подгонки (вывод ревьюера на каждого).
