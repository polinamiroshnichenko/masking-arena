# Условия кампании (черновик к ЧП1 — окончательно фиксирует агент подготовки)

Статус: **не заморожено**. До поиска остаются пункты «Открыто».

- **Две кампании** на одних данных и одном пакете метрики ([ADR-0006](../../docs/adr/0006-two-campaigns.md)):
  - `cases/pii-masking-ru/campaigns/mask` — только примеры `task = mask`, score = H·φ(P);
  - `cases/pii-masking-ru/campaigns/unmask` — только примеры `task = unmask`, score = A.
  Журналы `…/<campaign>/search.sqlite3` вне Git. Данные кампании: `tools/select_task.py --task <mask|unmask>`.
- Версия метрики: `pii-mask-v1` (сейчас `pii-mask-v1-draft`; заморозка после проверки на реальных текстах).
- Данные: `pii-ru-synth-v1` — train 1700, public 600, private 900 (`case/dataset/manifest.json`).
- Модель исследователей и оркестратора: **Открыто** — Claude (Claude Code) или DeepSeek V4 Flash по API курса; индекс Artificial Analysis не ниже DeepSeek Flash. В отчёте: модель, версия, индекс, дата проверки.
- Модель решателя и судьи: нет (решатель и метрика без LLM, ADR-0005).
- Разрешённые изменения: содержимое `ways/<candidate>/` (код, правила, словари, параметры) — см. `case/prompts/README.md`.
- Образ runner: штатный `arena/runner` (python:3.12-slim) для stdlib-кандидатов. **Открыто:** образ с закреплёнными natasha/slovnet, pymorphy3, razdel и весами в `/assets`. Состав фиксируется до старта.
- Таймауты: решатель — 60 с на пример (`ARENA_RUNNER_TIMEOUT`), метрика — 60 с на пример, агрегация — 600 с.
- Условия сравнения (`conditions` журнала): `pii-mask-v1 + runner-image digest + dataset pii-ru-synth-v1`.

## Лимит предложенных решений: 90 (mask) + 30 (unmask), предварительно

| Кампания | train / public / private | baseline train / public | SE score public / private |
|---|---|---|---|
| mask | 1200 / 420 / 630 | 0.645 / 0.535 | ≈0.015 / ≈0.012 |
| unmask | 500 / 180 / 270 | 0.443 / 0.542 | ≈0.013 / ≈0.010 |

- Стоимость кандидата: оценка без LLM — ~10 с на полный train локально, ~3 мин на public через runner. Основная стоимость — токены исследователя на гипотезу и код, ориентир 50–150 тыс. токенов на кандидата.
- Ожидаемая сходимость: быстрые скачки на дешёвых гипотезах (контекстные регулярки для адреса и даты рождения, устойчивость к искажённым меткам, склонение ФИО), затем медленный рост на ML-компонентах (NER, словари) и их комбинациях. Плато ждём после 60–80 решений; запас нужен для второй волны после подключения библиотек.
- Восстановлению меньше лимита: задача уже (нормализация меток + склонение), плато ожидается раньше.
- Пилот: первые 10 решений кампании mask покажут реальную стоимость кандидата; после этого оба лимита фиксируются до старта основного поиска.

## Финализация
- mask: финалистов K = 4, итоговых N = 2. unmask: K = 3, N = 1.
- Правило выбора K: лучший train/public, при этом разные подходы (чистые правила / с NER / с морфологией). Учитываются стабильность на подвыборках train и признаки переобучения: зазор train↔public, правила под конкретные формулировки train. Кандидаты с хардкодом значений из train к private не допускаются (ревьюер).
- **Связка:** лучший маскировщик + лучший восстановитель объединяются в навык. Оператор один раз прогоняет связку и baseline на полном private (mask + unmask) полной формулой H·φ·A. Это проверка вне кампаний, после неё ничего не дорабатывается.
