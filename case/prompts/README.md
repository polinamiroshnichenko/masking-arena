# Уточнения кейса для исследователей

Задача, форматы и метрика — `case/README.md`. Общие правила — промпты арены.

**Что меняется (разрешённые изменения):** только содержимое каталога своего кандидата `ways/<id>/` — `solve.py`, модули, правила, словари, параметры и выученные на train артефакты. Решатель обрабатывает оба типа задач (`mask` и `unmask`).

**Что зафиксировано:** метрика и `policy.json`, данные и split, формат входа и ответа, образ runner и список библиотек в нём, таймауты. Модели нет: решатель работает без сети и без LLM.

**Запрещено:**
- хардкодить значения ПДн, документы или формулировки из train (словари значений, выученные на train, не обобщаются: фамилии, улицы и шаблоны в public/private другие);
- читать что-либо кроме входа примера и разрешённого `/assets`;
- менять текст вне меток.

**Полезные направления для гипотез** (не обязательные):
- контекстные слова и окна вокруг кандидатов;
- контрольные суммы (СНИЛС, ИНН, карта), чтобы отсечь похожие числа;
- морфологические словари имён;
- малые NER-модели;
- склонение ФИО по контексту (предлог, согласование) для unmask;
- нормализация искажённых меток;
- согласованная нумерация одной сущности в разных падежах.

Замеры на train сохраняются с составом подвыборки; public возвращает только общий score.
