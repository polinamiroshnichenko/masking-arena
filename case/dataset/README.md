# Данные `pii-ru-synth-v1`

## Источник
Синтетический генератор [`generator/`](generator) (код в Git, только stdlib). Содержимое — шаблоны и пулы значений — хранится у оператора в `operator/content/` до финализации ([ADR-0004](../../docs/adr/0004-data-and-split.md)). Шаблоны написаны с помощью LLM-агента в разных стилях; склонение ФИО проверено по pymorphy3.

```bash
uv run python case/dataset/generator/generate.py --split train --n-mask 1200 --n-unmask 500 \
    --content operator/content --secret operator/secret.json --out case/dataset/train.jsonl
```

## Одно распределение
Все split'ы делает один генератор с одними параметрами (типы документов, их веса, форматы значений, шум). Различаются только семейства шаблонов и значения открытых классов, случайно разбитые секретным сидом. Распределение семейств одинаково в ожидании; конкретные split'ы различаются частотами классов — см. `manifest.json`.

## Семейства
Семейство — один шаблон со всеми перефразами (альтернативами `[а|б]`): одинаковая фраза с разными формулировками не может оказаться в двух split. Разбиение 2:1:1 стратифицировано по (тип документа, позиция в документе) с ограничением: в каждом split каждый класс ПДн встречается хотя бы в 2 семействах документов и хотя бы в 1 семействе ответов. Итого семейств документов: train 81 / public 49 / private 47; ответов: 23 / 12 / 12. Фамилии, улицы и названия организаций разбиты 50/25/25: запомнить значения train бесполезно.

## Размеры и обоснование
| Split | mask | unmask | Почему столько |
|---|---|---|---|
| train | 1200 | 500 | анализ ошибок по каждому классу (≥290 сущностей класса), свои подвыборки |
| public | 420 | 180 | SE score ≈ 0.011, SE парной разности ≈ 0.005 (бутстрэп); ≈ 3 мин через runner |
| private | 630 | 270 | один прогон K финалистов; SE ≈ 0.009 (парная ≈ 0.004) для надёжного выбора N |

Бутстрэп: `results/data/bootstrap_baseline.json`, `results/data/bootstrap_paired_probe.json`. Стоимость замера: 0.31 с на пример через Docker-runner арены (`results/arena_smoke_runner.txt`), локально ~20 мс.

## Формат
UTF-8 JSONL, одна запись на строку, по контракту `Example` арены. `input` и `reference` — JSON-строки:
```json
{"id": "train-m-00000", "input": "{\"task\": \"mask\", \"text\": \"...\"}",
 "reference": "{\"task\": \"mask\", \"spans\": [{\"start\": 0, \"end\": 21, \"label\": \"ФИО\", \"entity\": 0}], \"ignore\": [...], \"meta\": {\"doc_type\": \"email\", \"families\": [...]}}"}
```
Для unmask `reference` содержит `segments` (неизменный текст между метками), `golds` (правильные формы) и `labels`. `reference` решателю не передаётся. Public и private хранятся у оператора вне репозитория и вне доступа исследователя.

## Проверка на реальных текстах (план к ЧП2)
30–50 открытых документов с реальными ПДн (опубликованные протоколы собраний собственников, решения органов власти, контактные страницы организаций), размеченных вручную в том же формате. Выборка в поиске не участвует; на ней проверяется, что метрика и ранжирование кандидатов на синтетике переносятся на реальные тексты.
