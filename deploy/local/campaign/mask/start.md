# Старт поиска: кампания `mask`

Работай как оркестратор по `prompts/start.md` и `prompts/orchestrator.md` этой арены (корень рабочей копии — `/workspace`). Каталог кампании: `/workspace/cases/pii-masking-ru/campaigns/mask`. Сначала прочитай `README.md`, `AGENTS.md`, `common/`, файлы кейса `cases/pii-masking-ru/` и `campaign.md`, `preparation.md`, `board/methods.md` этой кампании.

Среда: Claude Code в изолированном контейнере. Исследователей, ревьюера и подбор альтернатив поручай субагентам (инструмент Agent): для продолжения текущей ветки — fork, для свежих идей — новый контекст. Отдельные ветки — в git worktree внутри `/workspace`. Интернет для открытых методов и документации разрешён.

Обязательно:
- регистрируй каждую версию в журнале `/search/search.sqlite3` до любого запуска (`evaluator.search propose`), используй выданные `S01`, `S02`, …; baseline `cases/pii-masking-ru/ways/baseline` регистрируется первым (S01);
- замеры train — через train-сервис (`evaluator.train submit/status/result`), public — `begin` + `evaluator.client pack/submit/wait` + `finish` только с общим score; каждое предложение получает public-оценку;
- веди `board/methods.md`; findings — в `findings/<S..>.md` кампании;
- лимит — {{MAX_SOLUTIONS}} предложений; при плато — раунд альтернатив по протоколу, без объявления потолка;
- не пытайся читать что-либо вне `/workspace`, `/search` и `/run/secrets`; закрытых данных в контейнере нет.

Практические детали контура (проверено оператором на приёмке):
- `evaluator.train submit` сам открывает проверку в журнале — не вызывай `begin` для train вручную; для public — `begin`, затем `pack`/`submit`/`wait`, затем `finish --score` (score — в `scores[0].score` файла `wait`).
- Повторная отправка неизменного кандидата на тот же набор возвращает сохранённый результат, а не новый прогон.
- Подвыборки train делай представительными по классам ПДн: итог — гармоническое среднее по классам и обнуляется, если класс в подвыборке пропущен целиком.
- Среда — неинтерактивный `claude -p`: когда ты завершаешь ход, процесс заканчивается и фоновые субагенты останавливаются. Не завершай ход, пока работают субагенты или проверки: запускай субагентов синхронно и дожидайся результата.
- Работа идёт на подписке с ограниченным лимитом: делегируй субагентам только действительно независимые направления, не запускай лишних разведочных агентов, держи findings краткими.

Если упрёшься в лимит использования модели, сохрани состояние (карта методов, findings, незавершённые проверки) — сессия будет продолжена оператором.
