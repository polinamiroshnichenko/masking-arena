# Маскирование ПДн (заготовка, наполняется на ЧП3)

## Когда использовать
«Отправь этот договор в модель, но без персональных данных», «обезличь письмо», «верни данные в ответ модели».

## Как использовать
```bash
python scripts/pii_barrier.py mask --input doc.txt --output masked.json      # текст с метками + таблица замен
python scripts/pii_barrier.py unmask --table masked.json --input reply.txt   # ответ модели с восстановленными значениями
```

## Ограничения
Классы v1: ФИО, адрес, телефон, email, паспорт, СНИЛС, ИНН, карта, счёт, дата рождения. Реквизиты организаций не маскируются.
