# tagger-t1: обучаемый токен-теггер ФИО поверх S02 (потомок rules-a1)

Меняется только детектор ФИО. `rules_a1.py` — копия `ways/rules-a1/solve.py` (S02) с выделенной `render()` (поведение прежнее). `solve.py`: спаны правил S02 + токены ФИО от теггера (p >= 0.07, не покрытые правилами; соседние токены через пробел/точку/дефис сливаются).

Теггер: логистическая регрессия (чистый Python, AdaGrad, L2=1e-2, 6 эпох), признаки `tagfeat.py` — форма и регистр, суффиксы 1–4 букв, признак «личное имя» по словарю `names_ru.py` (общие знания, не из train), окно ±2, класс разделителей, позиция в строке. Идентичность слов (имена, фамилии, улицы, служебные слова) в признаки не входит.

Происхождение обучающих данных: `weights.json` (11872 признака, 235 КБ) обучен `python train_tagger.py fit <train.jsonl> weights.json` на метках ФИО train (1200 mask-примеров, `dataset/train/dataset.jsonl`, основание — «правила, словари и параметры, выученные на train» в `campaign.md`). Значения ПДн train в веса не записываются как строки; признаки — суффиксы до 4 букв, формы, разделители и бинарные индикаторы.

Валидация (офлайн-обучение, не замер журнала): `python train_tagger.py cv|cvname <train.jsonl> <S02-train-result.json> K` — group-CV по `meta.families` и по основам фамилий; результаты — в findings кампании.
