# robust-x2: исправления robust-x1 (S05) после разбора его train-ошибок (потомок S05)

S05 дал train 0.99983, но разбор его ошибок (`runs/S05-train-full.result.json`) выявил регрессию и остаток:
- Слово «мая» (родительный падеж месяца) стало ФИО: исправление ложной неоднозначности «яна» (форма, совпадающая с именительным однозначного имени, считается неоднозначной = нет) распространилось на «мая» из списка имён. Теперь названия месяцев в родительном падеже входят в стоп-список, а форма «мая» помечена как совпадающая с обычным словом.
- Список `COMMON_COLLISIONS`: формы имён, совпадающие с обычными словами («люди», «людей», «жене», «музей», «улей», «аллей», «левой», «гелий», «лени», «рому» …), принимаются только как неоднозначные (заглавная не в начале предложения, либо после глагола общения).
- Неоднозначное имя перед глаголом речи/действия («вера обещала», «лев сказал») принимается в любом регистре.
- Тип улицы без точки в чате: «ш Заводское 8», «пл …», «мкр …».
- Даты рождения с двузначным годом только по явному ключу рождения («Дата рождения: 05.03.90»).

Остальной механизм — как в robust-x1 (см. ways/robust-x1/README.md). Проверки на вымышленных строках: `python3 shifted_checks.py`, `python3 synthetic_checks.py`.
