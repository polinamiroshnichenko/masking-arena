# robust-x1: обобщающие исправления остаточных ошибок и режимов отказа names-n1 (потомок S03)

Изменения относительно names-n1 (структурные классы, словари, natasha PER — без смены общей схемы):
- ФИО-шаблоны и инициалы работают только по горизонтальным пробелам (раньше «Титова\nАлександра Дмитриевна» склеивались в один диапазон); ведущие обращения и титулы («Уважаемая», «Дорогой», «Господин», «гр.») обрезаются из диапазона и не считаются фамилиями.
- «по имени Руслан» больше не блокируется словом «имени»; после «г.», «город», «пос.», «деревня», «село» слово — топоним, а не имя; названия улиц в творительном («проспектом Мира») не принимаются за имя.
- Заглавные слова целиком (подписи, шапки): ИВАНОВ ИВАН ИВАНОВИЧ; нижний регистр: отчество строгих суффиксов рядом с именем («вера павловна», «артёму сергеевичу»); неоднозначное имя после глагола общения («скажи вере», «спроси марка») и в строке автора реплики «10:20 вера:»; форма «яна» больше не считается неоднозначной из-за родительного падежа «Ян».
- Слово в начале предложения, найденное только NER и похожее на глагол («Пришёл Эльнур Гусейнов»), не добавляется к имени.
- Словарь имён расширен по общим знаниям (не из train).
- Даты рождения: «Рождественская» больше не ключевое слово «рождения», ключ на предыдущей строке («Дата рождения:\n05.03.1990»), «свидетельство о рождении выдано …» — не дата рождения.
- Адреса: тип улицы после названия («Невский пр., д. 28», «Красный проспект, 25»), составные города с заглавной после дефиса («Санкт-Петербург»), «д. Ольховка», «ул. 50 лет Октября», «мкр. 7-й», «площадь участка 1500» не адрес.
- Телефоны: «(495) 123-45-67» без кода страны, «8 (3822) 55-12-34», точки как разделители.

Проверки на вымышленных строках (значения не из train/public): `python3 shifted_checks.py` (сдвинутые проверки, части h-*, n-* контрольные) и `python3 synthetic_checks.py`. Для NER нужен natasha (в образе runner есть).
