# names-n1: ФИО через словари имён, морфологию окончаний и NER natasha (потомок rules-a1, S02)

Меняется только детектор ФИО: `fio_spans` в `solve.py` (структурные классы, АДРЕС, unmask — как в S02). Механизм:
- словарь русских имён (мужские, женские, уменьшительные; составлен по общим знаниям, не из train) с порождением падежных форм по окончаниям; неоднозначные имена (вера, роман, марта, света...) принимаются только с заглавной буквы не в начале предложения либо рядом с однозначным признаком ФИО;
- отчества по суффиксам (-ович/-евич/-овна/-евна/-ична и падежные формы), фамилии по суффиксам (-ов/-ев/-ин/-ский/-енко/-ян... и падежные формы) принимаются только рядом с признаком ФИО либо по NER;
- NER natasha (NewsNERTagger, PER): модели лежат в пакете natasha; при недоступности — предупреждение в stderr и работа без NER;
- нижний регистр (чат): однозначное имя в любом регистре, «имя фамилия» строчными, если фамилия с суффиксом;
- инициалы до/после распознанного имени или фамилии, двойные имена и фамилии через дефис, слова-обозначения улиц и «имени» блокируют ФИО.
Проверки на вымышленных строках: `python3 synthetic_checks.py`.
