# operator/ — закрытый контур оператора (вне Git до финализации)

Здесь у оператора (автора проекта) лежит то, что исследователь арены видеть не должен (ADR-0004):

| Путь | Что | Почему закрыто |
|---|---|---|
| `content/families.py` | все семейства шаблонов документов и ответов модели | формулировки public/private = утечка split |
| `content/pools.py` | пулы фамилий, улиц, организаций | по ним можно выучить значения public/private |
| `secret.json` | сид разбиения семейств/пулов и сиды split | по нему восстанавливается разбиение |
| `data/public.jsonl`, `data/private.jsonl` | закрытые разделы (600 и 900 примеров) | public отдаёт только score, private — ничего |
| `results/` | подробные результаты на public/private | исследователь получает только общий public-score |

После private-оценки финалистов каталог коммитится целиком: тогда все цифры отчёта воспроизводимы из клона. Резервная копия до этого момента — в закрытом хранилище оператора (не в публичном репозитории).
